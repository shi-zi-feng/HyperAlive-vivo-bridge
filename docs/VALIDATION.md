# 0.6-test 脱敏验证记录

## 测试对象

- 测试日期：2026-11-15。
- 设备：iQOO 12 / V2307A。
- 系统：OriginOS 6，Android 16，PD2307C_A_16.2.20.3.W10。
- 原版：HyperAlive 1.0.3，SHA-256 `55dca774ea69f3881db52ddcc60a491f626b8e761ec340cec031f4c8003a4946`。
- 附加模块：0.6-test，SHA-256 `81e0a1ddd3265f6b4daca3ad5b40df1c61ddb652881879ca575355062cc126eb`。
- 配置：HyperAlive 为当前锁屏动态壁纸，系统 AOD 开启，模块自定义 AOD 时钟可见；成功采样走 SystemUI 集成 AOD 路径。

## 已确认结果

1. 使用者手动重新加载框架、首次解锁后，明确反馈“模块样式可以持续显示”。
2. 在一次固定熄屏采样中，约 4.20 秒和 20.22 秒均为 `mWakefulness=Asleep`。
3. 20 秒时，框架 screen state 为 OFF，实际显示为 DOZE_SUSPEND。vivo `setAodDisplayState` 接受系统请求的 3 / 4 状态。
4. 20 秒合成截图中，星球壁纸、模块时钟、日期和电量可见，只出现一套时钟。
5. 日志触发 `Custom AOD clock ready; gated vivo time/date branches`。唤醒记录出现 `Native clock drawing restored`。
6. 构建包含 43 项纯 Java 策略检查，并通过 APK 签名验证；这些检查不能替代物理屏幕观察。

截图只能说明合成内容，物理屏幕是否持续发光由用户观察补充确认。此次采样不能证明数小时稳定性或耗电表现。原生 AOD 下 dumpsys 某些亮度字段也可能为 -1，不能仅根据该值判定黑屏。
